# 題目通過率分析（2026-11-07）

問題：720 題裡 0 題可用、424 題選擇題被退回。是內容真的很差，還是別的原因？

結論：**主因是規則和流程，不是內容本身。** 真正有品質疑慮的題目大約只有一成，但教學和回饋普遍有「寫給審查者看」的殘留文字，需要清理。

資料來源：`content/reports/question-quality-current.json`（v3 稽核結果）、`content/records/pilot-230/merged/`，以及 20 詞切片 40 題、20 篇教學的逐題人工閱讀（`content/history/question-assessments-slice20/ASSESSMENT.md`）。

## 1. 被退回的 424 題：418 題只因為選項不是四個

| 退回原因組合 | 題數 |
| --- | ---: |
| 必須四個選項 + 缺獨立語意審查 | 363 |
| 必須四個選項 + 缺獨立語意審查 + 現有審查有未解決問題 | 53 |
| 必須四個選項 + 其他（審查清單不完整） | 2 |
| 寫作題（已排除、隔離） | 4 |
| 不是選項數的問題（審查有未解決問題） | 6 |

選項數分布：2 個選項 326 題、3 個選項 252 題、4 個選項 138 題。

原因很單純：

- 出題規則 v1（`content/prompts/v1/author.md`、`check-author.md`）寫的是「**至少兩個選項**」，範例本身也只有兩個選項。
- 內容出完以後，v3 政策才改成「檢查題必須四個選項、練習題預設四個，三個選項一律不能用」。
- 所以這 418 題是**規則事後變嚴**造成的，不代表題目寫錯。

## 2. 待審的 292 題：缺的是「有人去審」

716 題選擇題裡有 713 題標示 `independent_semantic_assessment_missing`。v3 要求每題要有一份與出題者不同的獨立語意審查，但這一步從來沒有人做，只有第一批修訂過的 3 題做過。

這是流程缺口，不是品質判斷。實際做下去的結果：

| | 題數 | 通過 | 不通過 |
| --- | ---: | ---: | ---: |
| 20 詞切片（皆為四選項） | 40 | 37（93%） | 3 |

3 題不通過的原因都一樣：干擾選項跟句子毫無關係，學生不認識目標字也能刪去法答對。

- art 練習題：law / war / aid
- job 練習題：map / bet / toy
- history 檢查題：weather / flavour

## 3. 真正有審查疑慮的題目：61 題（8.5%）

v3 高風險清單的 61 題，是現有審查留有未解決問題的題目。這才是內容品質真正有疑問的部分，大約占選擇題的 8.5%。

## 4. 不擋 gate、但會影響學生的問題

這些問題 v3 gate 抓不到，是逐題閱讀時發現的：

| 問題 | 抽樣（20 詞） | 全題庫估計 |
| --- | --- | --- |
| 教學說明夾雜寫給審查者的句子，例如「本目標」「不列為證據」「已分開記錄的義項」 | 9 / 20 篇 | 關鍵字掃描有 104 / 360 篇（29%），實際只會更多 |
| 回饋提到題目裡沒有的東西，例如另一題的情境或教學例句：「不是保護環境口號或仙人掌棲地定義」 | 約 13 / 40 題，其中練習題約 12 / 20 | 關鍵字掃描抓不準；依抽樣推估約三分之一 |
| 題幹硬塞排除條件：「nonmilitary」「not merely」「rather than preventing it」 | 約 8 / 20 題檢查題 | 關鍵字掃描至少 40 題 |
| 題幹直接給出定義：job 題的「paid position」 | 1 / 40 | 未統計 |

成因推測：審查→修改→再審查的循環很長（有些題目改到第 10 版）。出題者為了回應審查意見（「跟教學例句太像」「可能有第二個答案」），往學生看得到的欄位補說明，而沒有直接改內容。

## 5. 小結

| 原因 | 影響題數 | 解法 |
| --- | ---: | --- |
| v1 出題規則允許 2–3 個選項 | 418 | 出題規則 v2：一律四個選項（已完成） |
| 獨立語意審查從未執行 | 713 | 逐批補審；20 詞切片已完成 |
| 干擾選項太弱 | 抽樣 3 / 40 | v2 規則 2；切片 3 題已附提案 |
| 現有審查的未解決問題 | 61 | 依原有 triage 處理 |
| 教學／回饋夾雜流程文字 | 約 30% | v2 規則 6、9；之後整批清理 |

真正會讓題目不能用的內容問題，約為 8.5%（61 題）加上抽樣中 7.5% 的弱干擾選項。其餘都可以用新規則重新生成，或補做審查來解決。

## 6. 下一步

1. 用 `content/prompts/v2/` 重新生成那 418 題的四選項版本：干擾選項重寫，題幹和正解盡量保留。
2. 每批生成後，交給另一個 session 做獨立語意審查，同 `content/policies/question-assessments-slice20.json` 的格式。
3. 整批清理教學和回饋的流程殘留文字。這需要另開一個修訂批次，修訂後的題目要重新審查。
