# 03｜學習、評分與記憶模型：要達成什麼

本文件只寫要求與驗收。可參考的演算法與起始數值見 `docs/08`「可參考的做法」，實作可以採用、修改或替換，只要滿足這裡的要求並記錄理由。

## 1. 學到的是考試能力

- 非書寫考試的主要能力是：**在句子或短文中，從英文選項選出正確的字／用法**。主力練習要直接練這個能力。
- 「看到英文、從上下文猜意思」和「句子留空、選出正確的字」是不同能力，不能互相冒充。
- 中英互譯、精確拼字是教學或輔助工具；只有考試需要英文書寫時，才要求回想與拼字。
- 一般學習中需要鍵盤輸入的題目只佔少數（上限見 `policy-v1.json` 的 `product.typing_window`、`product.ordinary_typing_max`），不必填滿。
- 短文小題組可以取代部分單題；共享的閱讀時間只算一次。文章中出現但沒被測到的字，不算複習過。

## 2. 義項與能力分開記錄，但不製造重複作業

- 同一個字的不同義項、用法，以及辨認／產出能力，證據要分開記錄：第一義熟不代表第二義會，選對不代表會拼。
- 片語獨立記錄，不從構成的單字推論已會。
- 分開記錄**不代表**每個義項 × 每種題型都要有自己的長期複習義務。下一步練什麼由目標與現有證據決定。
- 同一次作答只算一次成本、最多一次獨立成功；未直接測到的能力不能因此算通過。
- **必須在 M3 pilot 前固定作答證據的最小語義**：每道題標記 primary target（教學義項／用法）與實際測量能力。例：`issue`「雜誌某一期」的語境選詞成功可更新該義項的對應辨認證據，**不得**提高 `issue`「議題」、發行動詞義、拼字或片語的正式能力狀態；`issue a warning` 的成功只直接支持該用法。資料表／模型容器形式可自行決定，但要有此類負向更新測試。
- 第二義依考試重要度引入，不必等答錯才教，也不必等第一義長期穩定；不一次開全部義項。指定的考試範圍不能因詞頻低被自動排除。
- 多義的教法是在不同語境的題目中交錯練習與糾錯，**不加**「你學過 A，它也常考 B」之類的說明。

## 3. 第一次學習

- 一次只教一個主要義項加一個相關用法，其餘可展開但不要求當下背。閱讀時間由學生控制。
- 不以辭典第一義為唯一基礎義；先教哪個義項由內容優先度與學生目標決定。
- 教學閱讀、看到答案都只是曝光，不是學會的證據。剛看完答案就答對，不算獨立回想。V1 不製作作答前的首字母、刪選項或先給翻譯等解題提示；正常題幹本身的語境線索不算額外提示。
- 相似詞、易混詞不要在第一次教學時一起出現；各自意義建立後才做辨識練習。

## 4. 題目有效才計分

評分前先確認：題目版本有效、答案未提前曝光、作答未被中斷／故障污染、題目真的測到 primary target 的能力（選項合理、唯一可答、不能靠詞性或荒謬選項秒殺）。利用題目本身的上下文推論是合法的考試能力，不應因「靠語境推論」一律降格；但也不能把特定語境下的答對自動延伸到其他義項、輸出能力或所有題型。

**V1 不提供作答前的額外解題提示。** 作答提交後需提供清楚、正確且簡短的回饋：正解、此句所用的義項／搭配，必要時解釋錯因或干擾項；回饋與解析可展開，**是學習曝光而非新的正式測量**。若作答前曾因看字典、舊草稿或其他意外而知道答案，仍需記錄已曝光及不能視為獨立測量的原因；不因刪除提示 UI 就刪掉這類資料邊界。

- 學生回報題目有問題：該題立即暫停，這次作答不影響掌握狀態。
- 答案無法可靠判斷時，結果是「無法計分」，不是答錯。
- **沒有獨立評分，不等於沒有風險**：略過、提前退出、反覆未取得獨立答案、題目隔離與剛看過解析，都要保留「尚待驗證」或曝光訊號；不冒充 Again，也不得因只統計願意作答的題目，就將整個考試範圍視為高掌握。必要時安排未曝光、合格的新檢查，不能為了數據漂亮而只評估完成者。
- **未提交的跨日／逾期題目不是記憶失敗**。未超過 01 §6 的停滯期限時允許續作，但原先的 presentation、曝光、提示及草稿時間不重置；若答案／選項早在前一天已填好，隔天僅按提交屬既有草稿完成，不能據此發出新的跨日延遲回想 Good。若這次作答無法可靠地區分當日獨立回想和先前已完成的答案，就保留完成紀錄、標記不適合記憶評分，不編造成功或失敗。
- 超過停滯期限後，原本未提交的呈現可作廢並換合格新題；保留曝光與已提交小題的歷史，不對未答內容產生 Good／Again、不將換題當作已學或已忘。題目曾被展示不等於已測量，且不能再冒充全新 transfer family。

## 5. 拼字與輸入

- 大小寫在任何題型都不扣分。
- 合法的英美拼法、引號、屈折形式由內容包明確列出才接受。
- 不能靠全域刪除連字號等方式讓不同的字變成同一個（re-sign 與 resign）。
- 輸入本身是另一個真實英文字時（form/from、trial/trail），不能只憑字元相近判對。
- 「想得起來但拼錯」可以和「想不起來」分開記錄，但仍只算一次作答。
- 無法判斷是否為可接受的同義答案時：無法計分，並標記內容需擴充。
- 書寫型考試才要求精確拼字；與當題目標無關的詞形錯誤，不擴大解讀成整個字不會。

## 6. 記憶模型與可替換的觀察解讀

**不可更動的原始事實**是：題目與 primary target／測量能力、內容版本與必要題幹快照、學生實際回答、答案是否先曝光、展示與提交時間、題型／family，以及使用的排程／評分版本。**FSRS 的 S／D、到期日及 Good／Again 映射屬有版本的衍生解讀，不是唯一真相。** 不可事後把未答變成錯誤、把看到解析變成成功；換模型時保留歷史映射及可驗證的重算途徑。

V1 **初始基線使用 FSRS-6**（21 個參數）[S09]，鎖定官方參考／所選實作版本及 license，逐筆做公式一致性測試；但**「選擇題答對即 FSRS Good、答錯即 Again」只是起始 adapter**，不是經真人驗證的普遍記憶心理學定律。初期可將符合有效測量條件的首次答對／錯誤分別映射為 Good／Again，查字、答案曝光、無法計分與中斷不得產生假的正式 grade；保留完整未映射事件供日後比較、校準與替換。不向使用者要求 Again／Hard／Good／Easy，也不以作答速度自評。

- 同日初次教學、答錯補救與跨日獨立測試的事件語義必須分開；先看到解答再選正確不能憑空新增穩定度。跨日舊草稿直接提交也不產生新的延遲 Good；具體門檻可調。
- FSRS 狀態的**正式更新只對該題已直接測量的 primary target × 能力證據生效**；同一題不對其他義項／拼字連帶 Good，也不迫使每個能力永久各有一份複習作業。Pilot 需明確測試這些轉移規則。
- 記憶模型應能在本機持續使用新增事件更新個人狀態。**重新擬合個人參數、改變映射或動態目標 retention 是候選改進**：樣本不足、未驗證有益或效果不穩定時，可靠的基線仍可使用，這些進階機制不能阻擋核心交付。
- 當候選模型使用過一批資料來擬合或反覆選方案，該批資料就不能永遠被標成「獨立最終驗證」。在看答案之前記錄預測；候選固定後用後續新資料驗證其校準，不把「預測較準」直接宣稱「真人學習較有效」。個人參數留在裝置，更新前後可退回，不能使排程無合理理由突然大幅跳動。
- 猜對、題目難度、周邊詞彙能力、選擇性略過，都可能令客觀對錯與無線索回想不同；起始 adapter 可以先依工程驗收試行，未來有足夠合法、自願的真人資料時再檢查其對不同義項／語境的預測效度並考慮更改；真人資料不是當前正式版工程交付的前提。不能僅靠公式一致性證明適配。
- 當時選題所用的模型、映射、參數及決策理由須可重建；目前依已知壞題排除後的狀態重算，與「假如當時改用別種教法會怎樣」的反事實估計須區分，後者不能當真人證據。

驗收：FSRS baseline 與鎖定參考實作輸出一致；同日／跨日／補救／時區／邊界及異常輸入有回歸測試；同一情境在新映射版本下可重新計算衍生狀態，但原始事件、曝光與版本不被改寫；現階段以可重現單元／整合測試及小型內容 QA 排除明顯錯誤；**不強制進行早期真人 pilot**，也不得以純 FSRS 模擬宣稱對真人未見題具有已驗證的學習增益。未來有可行的真人資料才評估模型預測與未見題的關聯。

## 7. 顯示給學生的掌握狀態

- 不顯示假精確的百分比（例如「掌握 97.3%」），用可解釋的證據狀態：未開始、學習中、基礎已驗證、目前穩定、需要加強、已暫停。
- 「穩定」需要跨日、跨不同語境、包含一次沒看過的檢查題的成功；不代表永久學會。若只在願意提交的少數題有高正確率，但許多目標反覆未有獨立證據，整體仍須顯示待驗證／範圍缺口，不能套用少數樣本的成功率。
- 一個字的狀態看當前目標範圍內各義項的最弱處，不取平均，避免「第一義很熟」掩蓋「第二義沒學」。
- 對目前考試已有足夠證據的能力，可以降低密集練習，但仍保留間隔檢查；之後答錯就恢復加強。歷史不清空，不改寫原始對錯。

## 8. 防止猜對與背題

- 單次選擇題答對不能顯示為穩定或完全掌握。
- 選項位置洗牌並保存順序；回來續答時不重新洗牌。
- 只換人名的同一句不算新語境；用來檢查的題目不能事先當例句展示，出過一次就不再算沒看過的題。過期未完成題若需要換題，不得重設原曝光紀錄來偽造新的檢查題。
- 純中英選項題不能單獨滿足一個義項的驗收，必須有語境題。

## 9. 衡量標準

模型中的記憶估計、證據狀態與到期日都只是工具。早期及後續比較要包含**原始範圍中未教過、無有效答案、反覆看解析與退出的項目**，不能只報「完成、可計分的題」的正確率。真正的結果是：**相同投入時間下，延遲後在沒看過的考試型語境題上的表現**。減少重複練習後，要以這個結果確認沒有以遺忘換取表面效率。記錄題型、語境 family、難度與曝光，以便分題型檢查預測是否準確。
