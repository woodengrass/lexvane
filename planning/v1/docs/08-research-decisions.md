# 08｜研究決策與未知事項

研究查核日期：2026-10-04。這份計畫區分三種依據：
- 已有研究/官方文件支持的方向；
- 本產品的可測試工程基線；
- 資料足夠後才應啟用的假設。

## 決策紀錄

## 2026-10-08｜V1 決策整合（產品取捨，不是已證實的最適值）

這天把 V1 改成以考試能力為目標：主力改為語境選詞、義項三層粗分級、能力證據分開但不各自產生複習義務、每日時間作為規劃預算、個人化本機運作。規則本身寫在 `PLAN.md` 的核心規則與 03、04；這裡只記理由。

- 理由：模擬顯示每個字拆成越多獨立複習單元，每天固定時間內能學的字越少；固定高 retention 的成本也偏高。
- 限制：這些模擬**沒有量到真人在短文與共享能力證據下的改善幅度**。要在 pilot／beta 比較相同投入時間下的延遲未見語境題、原始範圍覆蓋與複習負荷；不能先寫死閱讀增加記憶的百分比，再用模擬證明它有效。

## 2026-10-10｜時間波動、跨日續題與群體研究的收斂決策

本節記錄取捨理由；正式可驗收規則分別在 01（互動）、03（作答證據）、04（預算／forecast）、06（QA）、privacy 文件（研究收集）及 tasks.json（派工），不在此重複定義另一套規格。

- **時間是意願，不是猜出的能力上限**：平常預算可改，另允許今天暫時覆寫；實際投入是 forecast 的訊號而非自動修改設定的理由。連續投入不足即使無考試仍應溫和提醒；必須避免「系統只安排短任務 → 實際短用 → 推斷學生只能短用 → 更少任務」的回饋迴圈。學生已做完現有內容與學生主動提早離開須區分。
- **預估預算，不強制截題**：預測成本用於避免主動安排超額的長活動；學生可以做完已開始的題，亦可自行暫停。不要設「每天精準零秒超額」或任意的固定可超時 3 分鐘標準，改看超時分布與長期低估。
- **短期延續、長期重新開始**：停滯約 72 小時是體驗窗口，不代表三天一定忘記；逾期只作廢未完成的題目呈現，不能偽造 Again、Good 或全新題目，已提交答案及曝光保留。跨日舊草稿直接提交不應偽裝成新鮮延遲回想。
- **部分時間也要有效，但不用另建 Anytime AI**：用既有選題規則與變動時長的模擬，防止高價值內容永遠排在學生做不到的尾端；也不能為提高前五分鐘的表面成果而不教新字或捨棄長文的必要閱讀成本。正式效益須等真人延遲新題比較。
- **群體研究很重要，但先縮小問題**：第一階段只驗證記憶預測校準及實際時間／工作量估計偏差，不先承諾完整 FSRS 聯邦訓練、學生流失預測或全詞義難度模型。離線 beta 不依賴研究服務；遠端研究是正式版的重要交付能力，須 opt-in 並通過對應安全聚合 gate。beta 版本若過渡採單一聚合方，不能宣稱具有正式版多方保護。

## 2026-10-11｜V1.4：先求可驗證，再做完整發布（歷史決策；早期真人 gate 已由 V1.5 撤回）

- **正式內容底線與先行試用不衝突**：正式 V1 全部涵蓋鎖定版本的大考中心參考詞彙表，可學、可查並通過授權；但在一萬詞級投入之前，先對 200 詞／30 片語的最小學習循環做自願真人跨日檢驗。這只是降低重做成本，不是要將正式 V1 縮成 pilot。
- **撤回演算法永久正確的承諾**：FSRS-6 與首次 Good／Again 是能重現的合理起始 adapter，不等於證明語境選擇題觀察符合回想模型。原始回答、題目、目標能力與曝光必須長期可用；模型映射、保留率和個人參數擬合可根據後續有效證據改版。
- **複雜功能若沒有增益就不預設**：對照者須拿到相近起始先驗、同樣內容／實際時間且有合理考試覆蓋，不能靠打敗「只清舊卡」之類弱基線宣稱成功。預測較準不等於教學增益；先以後續獨立資料確認，不能把反覆選模型用過的最近資料仍當最終乾淨驗證集。
- **不把缺失當正確**：跳過／看解析／答題中斷／壞題不算 Good 或 Again，但持續缺乏獨立成功也不得讓整個範圍被顯示成穩定。不可行的時間安排允許捨棄部分目標的密集維持或延後深度，必須誠實揭露。
- **題目品質會限制規模**：保存未見題消耗與重用、AI 盲點的普通題隨機抽查、獨立小批評估題；修正教錯的知識要提供更正，不只重算事件。歷史 replay、在新版規格下重算、反事實模擬不是同一概念。
- **回報缺詞與研究統計分離**：逐次可讀文字回報要求使用者預覽及確認；群體記憶／耗時校準則須配合 opt-in、限額、同一份報告去重、防濫用及可解釋的統計單位，不將 report 數說成人數。研究證據不足就降低模型承諾或縮小統計問題，不降低隱私保證。

這些原則只在此記錄取捨理由；正式驗收／依賴分別見 docs 01–06、privacy 和 tasks.json。V1.4 當時曾設計 T035 早期真人 gate 阻擋 T025；**V1.5 已將此硬依賴改成工程／內容品質 gate，真人研究可延後**。小樣本沒有顯著差異只代表證據不足，不自動證明新策略無效，但也不能拿它當上線預設的理由。

## 2026-10-11｜V1.5：真人實驗不再是正式 V1 的前置條件

使用者目前不方便招募同學或進行跨日真人測試，因此**不以真人研究阻擋開發、完整官方詞表內容製作或正式發布**。V1.4 的 T035 早期真人 gate 改為使用小型詞庫及最小學習循環完成**可重現的程式測試、題目盲解、普通題隨機／高風險抽查、未見題庫存與成本模擬、資料保存／續接／回饋驗收**；發現重大內容或事件語義問題先修正再量產。T025 仍依賴 T035，但依賴的是**工程與題目品質檢查，不是受試者、真人效益或統計顯著性**。

T029–T031 的自願 beta 與真人教學策略比較保留為**未來有條件時再執行**，不作正式 V1 發布依賴；研究收集的 opt-in、安全聚合與隱私門檻仍依 privacy 文件要求交付，不能因省略真人實驗而降低。模擬與 self-test 可以排除明顯錯誤，但無法證明語境克漏字的 FSRS adapter 真正有效、動態排程勝過簡單方法或提升學測成績。沒有此類真人證據時，可靠簡單基線維持預設，不對外宣稱已證明學習成效優勢。

## 可參考的做法（非要求）

以下是規劃時查過、或在模擬中表現合理的做法，供實作參考。可以採用、修改或替換；替換時記錄理由，並確認仍滿足 03、04 的要求。起始數值放在 `contracts/policy-v1.json` 的 `reference_starting_points`，同樣不是要求。

**記憶模型**
- FSRS-6 是首版**可重現的排程基線**，有效語境作答轉 Good／Again 是可版本化的 adapter（03 §6），不是永遠固定的心理學真理。實作選擇可研究 swift-fsrs [S10] 或 fsrs-rs；實際最新版本、參數數目、Swift／Rust 支援與 license 必須在實作時查證，不能假設舊版 package tag 一直不變。
- 練習／同日／延遲的門檻：穿插至少 3 個其他題目才算獨立回想、距上次曝光 24 小時以上才算延遲回想。
- 為什麼選 FSRS：它是公開比較中（srs-benchmark，Anki 資料）表現最好的非神經網路模型，有 Swift 與 Rust 實作，可在手機上逐人擬合；比它準的多為需要大量資料的神經網路模型。它不是為選擇題設計的，猜對的影響要在 beta 實測。
- 查字污染：先看答案／查字後重新回答不能算獨立成功，必要時安排未曝光的確認。**看到解析之後的再次答錯也不能自動假稱獨立 Again**；只有本身合格、未提前曝光的正式作答失敗才按當前 adapter 處理。所謂 reanchor 是待真人驗證的候選做法。
- 候選持續個人化的防護思路（**舊模擬不能證明真人最佳**）：拉回族群或預設參數的正則化、依時間遞減的資料權重（約 60 天半衰期）、只在 held-out 預測變好時採用、每次只走一部分（約 0.6）、不立刻重排既有到期日、每次變動設上限、可退回。有群體研究結果後可改用族群參數當起點。
- 選擇題猜測修正：可參考 Bayesian Knowledge Tracing 的 guess 參數，但 V1 不預設採用，等 beta 實測。

**證據狀態門檻**：基礎已驗證約為 2 次無提示成功、2 種語境、其中 1 次延遲；穩定約為 3 次延遲成功、跨 3 個日期、含一次 7 天以上間隔與一次沒看過的檢查題。

**候選動態目標記憶率（非正式 V1 必啟用）**
- 參考 Anki 25.07 以後「依個人參數模擬記憶率與每日工作量」的做法（CMRR 已移除），但由系統選，不讓使用者選。
- 一種做法：對少數候選設定（各價值層的目標組合）跑 forecast，有考試時比較考試當天、範圍內價值加權的預期答對（未接觸以不會計）；無考試時比較約 90 天的價值加權預期記憶；每週或條件變動時重選，每次變動設上限。範圍可先限制在 0.70–0.95，從 0.90 起步。
- 進一步可參考 SSP-MMC（Ye et al., KDD 2022）。

**出題順序**（舊模擬中的候選啟發式；時間不足不可能無條件維持全部目標）
1. 續接正在作答的題目。
2. 當天的補救與必要教學（同日接著看答案後的練習只作輔助曝光，不複製成獨立 Good；補救強度要考慮真實花費）。
3. 關鍵維持：基礎層或考試範圍內、預測記憶低於目標超過約 0.10 的到期項目。
4. 考試覆蓋配額：範圍內仍有未接觸內容時，依「剩餘未接觸量 ÷ 剩餘學習日」保留新內容時間；此時維持類最多用約 70% 的預算。
5. 其他到期項目，依價值加權的風險排序。
6. 一般新內容：未來 14 天每天的預估複習都不超過預算約 85% 才開（參考 Reddy et al., KDD 2016 的臨界加入速率、Anki load balancer）。
7. 查字後的診斷與跨語境檢查，最多約 10% 預算。
8. 有餘裕再擴展義項與用法。
同層排序可用：期限 → 價值層 → 低於目標的幅度 → 等待天數 → 預估成本 → 穩定 ID。缺天回來的處理可參考 SuperMemo auto-postpone。

**內容層級對應**：內容分級「基礎優先／常用補充／延後學習」可對應規劃的 Foundation／Standard／Extended，再依考試範圍、題型與是否書寫調整；考前先暫緩 Extended，再收窄 Standard。

**個人耗時**：依「單字／片語 × 初次教學／複習 × 題型 × 成功／失敗」分桶；`成本 = w × 個人中位數 + (1 − w) × 先驗`，`w = n / (n + 30)`；規劃用 P75；每桶保留最近 200 個有效樣本即可。超過約 120 秒無活動的尾端標為不確定時間。

**Forecast**：固定 seed 的約 32 條模擬軌跡，逐日執行與實際相同的選題規則；至少看未來 14 天，有考試時涵蓋到最近的考試、最多 90 天。近期投入的時間、缺席日比例可作預估情境的弱訊號；用「設定的時間」和「觀察到的投入」產生不同情境，不回寫使用者設定。持續低於預設時間的提醒可先以約 14 天觀察窗、至少數週提醒冷卻作工程試驗值，沒有足夠活動內容時不觸發。

**分層規劃**：每日規劃（決定當天的時間分配與可學目標，在換日、大量加入、考試或預算變動時重算）與下一題選擇（在當天限制內快速挑題）分開，避免兩套排程互相搶控制權。

## 工程初值的修改規則

改 `policy-v1.json` 的任何值都要：版本化並說明假設；跑 deterministic 回歸與受影響事件的 replay；用延遲新題、有效時間與負擔觀察，不只看當下分數；涉及評分標準或舊資料語義時保留舊版本，不靜默覆蓋。

## 認真保留的未知問題

- 二元 Again／Good 的初始 adapter 是否能在混合 recognition 與語境推論下，可靠預測新的延遲題；FSRS baseline 的公式正確性不能代替此驗證。
- 題目難度對記憶估計的偏差，以及片語/單字成本先驗差异。
- 自願查字對後續回答的提示效應；目前 reanchor 是保守設計，需防過度複習。
- 長文／選擇題訓練對實際試題的轉移，不以題型外觀相近保證，也不將篇章中每個出現過的字當成通過複習。
- 目標深度縮減在考前的 coverage/retention 取捨。
- 手機零碎使用的計時誤差与個人有效時間估計。
- 個人化與動態 retention 的**額外教學收益**需要跨日未見題與合理簡單 baseline，控制題目難度、先備知識和被系統選中的偏差；舊模擬的補救計分／耗時與不同策略使用的族群先驗可能不一致，不能不經核對直接當新版本的數值證明。

這些不是開發前必須向使用者詢問的選项；先把可測基線與資料收集（本地）做對，再用測試者自願資料改進。

## 後續研究候選（V1 不實作）

- **校準器**：以 FSRS 的 logit(R)、題型、詞／片語種類、實際 lag、提示、近期錯誤等特徵，訓練正則化 logistic 校準器；held-out 評估有改善才啟用。[S08] V1 不訓練大型 DKT，不把 IRT 的資訊量最大化當成學習收益最大化。
- **時長與效率**：用題型、長度、target 熟悉度、lag、是否提示、連續學習時長、當日累計時長預測延遲後未見題表現；比較加入時長特徵能否在 held-out 資料改善預測。先跑 shadow mode，不直接干預。樣本不足時不輸出「你最佳學習上限是 37 分鐘」之類的結論。模型經實驗確認後，才用個人化的延遲收益取代固定比例。
- **比較基線**：HLR、logistic knowledge tracing。[S07][S08]
